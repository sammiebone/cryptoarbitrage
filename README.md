# Automated Crypto Arbitrage Service

This service is designed to automatically find and execute cryptocurrency arbitrage opportunities across various exchanges.

## Project Status

This project is currently under development.

## Setup

1.  Clone the repository.
2.  Install dependencies: `pip install -r requirements.txt`
3.  Configure the service by copying `config/config.yaml.example` to `config/config.yaml` and filling in your details.

## Usage

To run the service:

```bash
python main.py run
```
